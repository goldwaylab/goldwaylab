# Noam Goldway

I study how people learn and make decisions, and how pain, dissociation and development shape them, using behavioral experiments, computational modeling and neuroimaging.

## Selected work

| Project | What it is |
|---|---|
| [ketamine-pain-dissociation](https://github.com/goldwaylab/ketamine-pain-dissociation) | Analysis code and data for *Ketamine-induced analgesia and dissociation show distinct behavioral and neural correlates* (*Neuropsychopharmacology*, 2026; [DOI](https://doi.org/10.1038/s41386-026-02496-x), [OSF](https://osf.io/k4wy5/)) |
| [con_pit](https://github.com/goldwaylab/con_pit) | Task, anonymized data and modeling code for *Adolescents flexibly adapt action selection based on controllability inferences* (*Learning & Memory*, 2024; [DOI](https://doi.org/10.1101/lm.053901.123), [OSF](https://osf.io/e49ua/)) |
| [Ketamine and embodiment](https://github.com/goldwaylab/Ketamines-effect-on-embodiment-in-a-virtual-environment-R-code) | R code for the effect of ketamine on embodiment in the Virtual Hand Illusion |

Each repository links to its paper or OSF project, states its license, and can be cited.
