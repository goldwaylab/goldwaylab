# Noam Goldway

I study how people learn and make decisions, and how pain, dissociation and development shape them, using behavioral experiments, computational modeling and neuroimaging.

## Selected work

| Project | What it is |
|---|---|
| [ketamine-pain-dissociation](https://github.com/goldwaylab/ketamine-pain-dissociation) | Analysis code and data for *The Analgesic and Dissociative Properties of Ketamine are Separate and Correspond to Distinct Neural Mechanisms* ([bioRxiv](https://www.biorxiv.org/content/10.1101/2025.07.25.666594v1), [OSF](https://osf.io/k4wy5/)) |
| [con_pit](https://github.com/goldwaylab/con_pit) | Task, anonymized data and modeling code for *Adolescents flexibly adapt action selection based on controllability inferences* ([OSF](https://osf.io/e49ua/)) |
| [Ketamine and embodiment](https://github.com/goldwaylab/Ketamines-effect-on-embodiment-in-a-virtual-environment-R-code) | R code for the effect of ketamine on embodiment in the Virtual Hand Illusion |

Each repository links to its paper or OSF project, states its license, and can be cited.
